# University Admissions Bot

## Project Description
The University Admissions Bot is an AI-powered chatbot designed to help students
understand university admission requirements and application guidelines.
The bot compresses lengthy admission information into short and easy-to-read responses,
making the admission process simpler and more accessible.

## Problem Statement
University admission procedures are often complex and difficult to understand.
Students face challenges in identifying eligibility criteria, required documents,
important deadlines, and application steps from long and unstructured guidelines.

## Solution
This project provides a chatbot-based solution that allows students to interactively
ask questions related to university admissions.
The chatbot responds with simplified and compressed information to guide students
through the admission process efficiently.

## Features
- Admission requirement summarization
- Application process guidance
- Eligibility-related query handling
- Text compression for easy understanding
- Student-friendly chatbot interaction
